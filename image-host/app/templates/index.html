A classic Macintosh on a tiny board

RPi-Mac turns a Raspberry Pi (Zero 2 W, Pi 4 or Pi 5) — or an Orange Pi (Zero 2, Zero 2W or Zero 3) — into a classic 68k Macintosh. Flash an SD card, power on, and it boots straight into a Quadra-class Mac — grey checkerboard, Happy Mac, desktop. No visible Linux anywhere.

Grab a ready-made image below. The single Raspberry Pi image runs on the Zero 2 W, Pi 4 and Pi 5 and comes in an HDMI flavour and one preconfigured for the Waveshare 2.8″ DPI LCD; the Orange Pi images are per-board and HDMI only. Or use the SD Card Builder (Raspberry Pi) to compose your own: pick the Mac OS disk images and install CDs you want on the card, choose your display, and bake in your WiFi settings, so the Mac is on the network the first time it boots.

  • Raspberry Pi (HDMI) — Zero 2 W, Pi 4 or Pi 5, for TVs and monitors. Plug in, flash, boot.

  • Orange Pi Zero 2 / Zero 2W / Zero 3 — HDMI only, one image per board. On these the boot files live on the Linux partition, so set WiFi from the web control panel or over SSH rather than by editing the card on another computer.

After flashing

  1. Flash with Raspberry Pi Imager ("Use custom") or balenaEtcher, onto an 8 GB or larger card. Skip the Imager's OS customisation step — the image manages its own users and WiFi.
  2. For WiFi: open mac.txt on the bootfs partition (visible from any computer) and fill in WIFI_SSID / WIFI_PASS. The stock images ship without WiFi configured — use the SD Card Builder instead if you want it baked in. Display and rotation can be changed in the same file.
  3. Boot the board. The first boot takes a few extra minutes: the filesystem grows to fill the card and the compressed Mac OS 8 system disk is unpacked (progress appears on the boot screen), with one automatic reboot along the way.

About the SD Card Builder

1. Compose

Choose from {{ counts.disk }} Mac OS disk image{% if counts.disk != 1 %}s{% endif %}, {{ counts.iso }} CD-ROM image{% if counts.iso != 1 %}s{% endif %} and {{ counts.rom }} ROM{% if counts.rom != 1 %}s{% endif %} in the library, add blank disks to install onto, and enter the WiFi network the Pi should join.

2. Bake

This server assembles a personalised SD card image: your picks are written into the system image and your settings into mac.txt, then everything is compressed for download. It takes a few minutes.

3. Flash and boot

Download the finished .img.xz, flash it like any other image, insert the card into a Raspberry Pi (Zero 2 W, Pi 4 or Pi 5) and power on. The Mac appears on your WiFi with a web control panel at http://rpimac.local/.

The builder customises Raspberry Pi images. For Orange Pi, download a stock image above and set WiFi from the web control panel.

Custom images contain the WiFi password you enter, so download links are private and builds are deleted from the server after 24 hours.
